## Project Overview

The Employee Recruitment & Applicant Tracking System (ATS) is a command-line Python application designed for companies and recruitment agencies.

The system helps recruiters manage job openings, candidates, job applications, interviews, application statuses, recruitment reports, and external job data.

This project combines Python programming concepts including Object-Oriented Programming (OOP), SQLite, REST APIs, JSON, file handling, error handling, logging, modules, packages, and Git/GitHub collaboration.

## Problem the System Solves

Recruitment can involve managing many candidates, job openings, applications, interviews, and application statuses.

This ATS provides one command-line system where recruiters can store and manage recruitment information, track candidates through different application stages, schedule interviews, search recruitment records, and generate recruitment reports.

## Features

The completed system will allow users to:

- Add and manage candidates
- Create and manage job openings
- Submit candidates to job openings
- Track application statuses
- Schedule and manage interviews
- Search candidates and applications
- Search job openings
- View applications for a specific job
- View applications submitted by a specific candidate
- Update and delete recruitment records
- Search external jobs using a public REST API
- View recruitment analytics
- Export recruitment reports
- Record important activities and errors in a log file

## Installation and Setup

Follow the steps below to set up and run the project on your computer.

### 1. Clone the Repository

Clone the project from GitHub:

    git clone YOUR_REPOSITORY_URL

Then move into the project folder:

    cd recruitment_ats

### 2. Create a Virtual Environment

Create a Python virtual environment:

    python -m venv venv

If `python` does not work on Windows, try:

    py -m venv venv

### 3. Activate the Virtual Environment

For Git Bash on Windows:

    source venv/Scripts/activate

For Windows Command Prompt:

    venv\Scripts\activate

For Windows PowerShell:

    .\venv\Scripts\Activate.ps1

For macOS/Linux:

    source venv/bin/activate

When the virtual environment is active, `(venv)` should appear in the terminal.

### 4. Install Project Dependencies

Make sure the virtual environment is active, then install the required packages:

    pip install -r requirements.txt

### Requests Library

The project uses the Python `requests` library for communicating with the external REST API.

If you are setting up the project dependencies manually, install Requests with:

    pip install requests

After installing or updating project dependencies, the requirements file can be updated with:

    pip freeze > requirements.txt

### 5. Run the Application

Make sure the virtual environment is active.

Run the application from the project root folder:

    python main.py

## Database Design

The application uses SQLite for persistent data storage.

The database contains four main related tables:

### Candidates
Stores candidate information such as name, email, phone number, location, skills, and years of experience.

### Jobs
Stores job opening information including title, department, location, salary range, status, and creation date.

### Applications
Connects candidates to specific job openings and stores the application date, status, and notes.

### Interviews
Stores interview information for applications, including the interview date, interview type, interviewer, and notes.

### Database Relationships

A candidate can have applications for job openings.

An application connects a candidate to a job using candidate and job IDs.

An interview belongs to an application.

## Public API Integration

The project will integrate a public REST API to enhance the recruitment system.

The planned primary API integration is an external job search API that will allow users to search for public job vacancies using information such as job title, keyword, or location.

The core ATS will continue to work if the API or internet connection is unavailable.
